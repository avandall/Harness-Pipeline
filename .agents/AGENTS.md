Toàn project này là template để làm mẫu harness engineering, chạy AI loop hoàn thành task qua đêm 100% auto tự sinh code - kiểm tra - phản biện - sửa lỗi.

Không implement code, không tự ý chạy harness.sh trong môi trường này trừ khi có lệnh rõ ràng từ người dùng. 

Chỉ làm việc, thay đổi các file trong /pipeline đây là src template mẫu. Giữ các docs trong pipeline là form template, không specify bất cứ code đặc biệt nào.

Luôn chỉnh file /home/avandall/project/boilerplate/pipeline/scripts/harness.sh để chỉnh sửa logic cho phù hợp với workflow mỗi khi có thay đổi khi thảo luận với user.
