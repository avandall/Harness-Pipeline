# The Visual Contract + Evidence Pack

> The per-page artifacts that replace "agent memory from a long conversation" and make the loop resumable. Authored in
> **CAPTURE** (`prompts/PLAN.md`), consumed by **the gate** (`scripts/visual-diff/contract-diff.mjs`). Harness note:
> this is the single most important harness idea — *externalize the agent's memory into files a machine can validate*.

## Folder layout — `migrations/<page>/`
```
migrations/<page>/
  contract.json        # target spec: sections + selectors + mustMatch + checks + measured targets   (TRACKED)
  assets.json          # exact source asset register: URL / local bytes / theme/assets destination / SHA-256 (TRACKED)
  dynamics.json        # dynamic inventory: overlays/popups/apps/forms/hovers/motion to classify         (TRACKED)
  visual-deltas.md     # GENERATED by contract-diff.mjs — open "- [ ]" = a current mismatch              (TRACKED)
  gate.json            # GENERATED by contract-diff.mjs — the machine verdict the loop gates on          (TRACKED)
  interactions.md      # behaviour inventory classified from dynamics.json; REBUILD rows are checkboxes  (TRACKED)
  reports/final.md     # the page's done report; reports/visual-verify.md — the eye-level pass           (TRACKED)
  source/              # captured source reference: full-page + per-section shots, styles, exact asset bytes (gitignored)
  reports/*.json,*.png # per-section diff results + diff/review images                                   (gitignored)
```
`<page>` = the route handle (`home`, `about`, `collection-all`). Underscore folders (`_example/`, `_queue.tsv`,
`_scope.json`, `_brief.md`, `_sections.md`) are harness files, not pages.

## `contract.json` — the target spec (authored by the agent; `targets` filled by tooling)
```json
{
  "page": "home",
  "source": "https://source-site.com/",
  "preview": "https://__SHOPIFY_STORE__/?preview_theme_id=__SHOPIFY_THEME_ID__",
  "viewports": { "desktop": 1440, "tablet": 768, "mobile": 390 },
  "sections": [
    { "key": "hero", "class": "structural",
      "sourceSelector": ".home-hero", "replicaSelector": "[data-section-key='hero']",
      "mustMatch": ["height", "background/video", "heading", "button-count", "spacing"],
      "checks": [
        { "selector": "[data-section-key='hero'] .button", "expect": { "count": 1 } },
        { "selector": "[data-section-key='hero'] a.cta", "expect": { "hrefEndsWith": "/collections/all" } },
        { "selector": "[data-section-key='hero'] .hero-media", "expectByViewport": { "desktop": { "aspect": 1.78 }, "mobile": { "aspect": 0.75 } } }
      ],
      "targets": {} }
  ]
}
```
- **`key`** — stable id; also the replica root's `data-section-key`. **`class`** — `structural` | `content` | `overlay`
  (overlay = full-screen layer, diffed in a separate `--keep-overlays` pass).
- **`sourceSelector` / `replicaSelector`** — the section root on each side; the diff screenshots **these exact
  elements** (drift-proof). Author the replica root as `<section data-section-key="hero" data-section-type="video-hero">`.
- **`mustMatch`** — human checklist surfaced in the report. **`checks`** — *enforced* child assertions the root diff
  can't see (`text`, `hrefEndsWith`, `count`, `minHeight`, `maxHeight`, `aspect`; `expectByViewport`, `viewports`).
- **`targets`** — filled by `capture-source.mjs`: the source element's box + curated computed styles per viewport.
- **`preview`** — always with the `__SHOPIFY_STORE__` / `__SHOPIFY_THEME_ID__` / `__SHOPIFY_PRIMARY_DOMAIN__`
  placeholders; scripts substitute `.env` (`scripts/env.mjs`). A reference source uses `"source": "__REF__/<dir>/index.html"`.
- **`pixelCeiling` / `boxCeiling`** *(per section, optional, with `_…Reason`)* — relax the smoke-detector threshold only
  for an irreducible cross-engine residual; the verdict stays strict equality. Never to wave through a real mismatch.

## `assets.json` — exact source assets (written by `capture-assets.mjs`)
Every rendered image/video/poster/`srcset` candidate/CSS background/inline SVG/font per section per viewport,
downloaded and re-fetched, SHA-256 compared (`verifiedExact`), with the theme destination:
`"publicPath": "theme/assets/hero-image-9f3c2a1b.webp", "publicAssetUrl": "hero-image-9f3c2a1b.webp"` → in Liquid:
`{{ 'hero-image-9f3c2a1b.webp' | asset_url }}`. `assetPass` must be `true` before BUILD; `validate-assets.mjs --public`
proves BUILD copied bytes unchanged. Third-party widget glyphs (apps the theme only mounts) are excluded via a
per-migration `skipSelectors` list.

## `dynamics.json` — dynamic inventory (written by `capture-dynamics.mjs`)
First-load / overlay-dismissed / popup-dismissed states, third-party hosts, forms, videos, motion, hover probes →
`mustClassify[]` items (`dyn-001`…). Every item must appear in `interactions.md` as `[dyn:<id>]` with `REBUILD`,
`DEFER-to-app`, or `DROP`; `validate-dynamics.mjs` fails on anything unclassified.

## `visual-deltas.md` — the punch-list (GENERATED, never hand-ticked)
`contract-diff.mjs` fully regenerates it every run; an open `- [ ]` = a real, currently measured mismatch. You fix the
section and re-run; the box clears itself. That is what makes "zero deltas" mean "matches the source".

## `gate.json` — the machine verdict (GENERATED)
Per required viewport: normal (and overlay) pass flags, `openDeltas`, `visualPass`, and the SHA-256 `contractHash` of
the contract. The loop treats a page as gated only when `visualPass === true`, `openDeltas === 0`, and the hash still
matches the live contract — so a stale report or a hand-written file can never fake "done".

## `interactions.md` — the behaviour inventory
```md
- [ ] [dyn:dyn-001] hero video autoplay + loop — REBUILD -> tests/video-hero.test.js
- [ ] [dyn:dyn-002] header dropdown reveals links — REBUILD -> tests/header-dropdown.test.js
- [dyn:dyn-003] newsletter popup (app) — DEFER-to-app (mount hook/app block note)
- [dyn:dyn-004] decorative scroll-reveal — DROP (note in final.md)
```
Only REBUILD rows are checkboxes (work to verify); DEFER/DROP rows are plain bullets so they never block the terminator.
